# AgentMetrics AI contribution rules

- One feature per branch: feat/<scope>, fix/<scope>, docs/<scope>.
- Use small Conventional Commits.
- Open a PR to main; verify CI before merging.
- Never fabricate benchmark results or claim synthetic data are real production data.
- Protect user prompts, credentials and personal information.
- Add tests for every metric and document assumptions, limitations and units.
- Prefer free, locally runnable dependencies.
